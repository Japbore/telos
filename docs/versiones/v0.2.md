### Cálculos Relacionados

| Cálculo | Fórmula |
|---------|---------|
| Objetivo diario de páginas | `ceil(págs_restantes_al_inicio_del_día / días_hasta_fecha_objetivo)` |
| Objetivo diario en minutos | `objetivo_diario_págs × (vel_pág / 60000)` |
| Minutos leídos ese día | `incremento_págs × (vel_pág / 60000)` |
| Porcentaje del objetivo | `minutos_leídos / objetivo_diario_minutos × 100` |
| Posición en gradiente | `min(porcentaje_del_objetivo / 120, 1)` — a partir de 120 % se satura en verde |

### Casos de Uso (Paso a Paso)

#### CU-05: Detalle de Tiempo por Registro
1. El usuario abre el historial de lectura en el dashboard.
2. Junto a cada entrada ve: la fecha, la página alcanzada, el incremento de páginas desde el registro anterior, el tiempo estimado de lectura de ese día y el tiempo medio diario entre ambas marcas.
3. El tiempo estimado de lectura se calcula como `incremento_págs × vel_test`.
4. El tiempo medio diario entre dos marcas se calcula como `(pág_actual - pág_anterior) / días_entre_marcas × vel_test`.

#### CU-06: Historial con Feedback Visual y Detalle
1. El usuario abre el historial de lectura en el dashboard.
2. Ve una tabla con fecha, última página e incremento de cada registro.
3. Cada fila tiene un color de fondo que refleja si el ritmo de ese día fue adecuado (verde), aceptable (amarillo/naranja) o bajo (rojo) respecto al objetivo diario calculado automáticamente.
4. El primer registro del historial se muestra sin color (gris), ya que no hay referencia previa.
5. Si no hay fecha objetivo configurada, todas las filas se muestran sin color.
6. Al pulsar sobre una fila, se abre un modal Bootstrap con información extendida: fecha, última página, incremento, tiempo total leído y tiempo medio diario.
7. El usuario cierra el modal pulsando fuera de él (backdrop) o en el botón de cierre (X).
